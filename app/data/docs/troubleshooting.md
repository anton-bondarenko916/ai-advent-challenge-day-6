# Устранение неполадок

Типичные проблемы и способы их решения.

## Запуск

### Окно не открывается

Проверьте, что установлен Python 3.11+ и зависимости: pip install -r requirements.txt. На Linux требуется пакет python3-tk. Если окно всё равно не появляется, запустите python main.py в терминале и прочитайте текст ошибки.

### Ошибка «Не удалось загрузить конфигурацию»

Файл .env повреждён или заполнен неверно. Скопируйте .env.example заново и укажите только DEEPSEEK_API_KEY — остальные переменные имеют разумные значения по умолчанию.

## Сеть и API

### Ошибка 401 в ответах

Ключ DeepSeek API неверный или отозван. Проверьте значение DEEPSEEK_API_KEY в .env, убедитесь, что на балансе аккаунта есть средства.

### Ошибка 429

Сработало ограничение частоты запросов. Подождите минуту и повторите; приложение автоматически повторяет запрос один раз.

## База знаний и RAG

### Ollama недоступна

Запустите ollama serve в отдельном терминале и проверьте адрес: по умолчанию http://localhost:11434. Скачайте модель эмбеддингов командой ollama pull nomic-embed-text. Приложение сообщит о недоступности и ответит без RAG — диалог при этом не ломается.

### Поиск не находит ответы

Индексируйте папку с документами на вкладке «База знаний». Проверьте, что файлы имеют расширение .md и папка указана верно. Увеличьте top_k, если ответ слишком короткий, или уменьшите chunk_size, если в контекст попадает нерелевантный текст.

### После переиндексации старые чанки пропали

Это ожидаемо: переиндексация полностью заменяет коллекцию, чтобы IDs чанков оставались уникальными и устаревшие чанки не накапливались.

## MCP-серверы

### Напоминания не срабатывают

Сервер напоминаний запускается автоматически вместе с приложением на порту 8000. Проверьте, что порт свободен. Если сервер упал, агент поднимет его автоматически при следующем вызове инструмента.

### Новости не загружаются

news-сервер (порт 8001) читает RSS-ленты lenta.ru и rbc.ru. Проверьте подключение к интернету; при недоступности лент вернётся пустой список новостей.
