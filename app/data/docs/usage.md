# Использование приложения

Основные сценарии работы с чатом DeepSeek Chat.

## Отправка сообщений

Введите текст в поле ввода внизу окна и нажмите Enter или кнопку отправки. История диалога сохраняется в SQLite и восстанавливается после перезапуска приложения. Кнопка «Очистить» удаляет историю диалога и сбрасывает статистику токенов сессии.

## Контекстное окно и токены

Приложение считает токены каждого обмена и показывает стоимость сессии. Когда история превышает лимит контекста, включается стратегия управления контекстом: sliding_window оставляет в запросе только последние N сообщений, sticky_facts извлекает ключевые факты, branching хранит диалог в виде веток.

## Режим с RAG и без RAG

Переключатель «Использовать RAG» включает поиск по базе знаний. С RAG вопрос сначала превращается в эмбеддинг, затем в векторной базе Chroma находятся топ-K релевантных чанков MD-документов, и они подаются модели в контексте. Под ответом появляется сворачиваемая панель «Источники» со списком использованных чанков. Без RAG вопрос уходит модели напрямую. Число чанков настраивается полем top_k (по умолчанию 3).

## Индексация базы знаний

На вкладке «База знаний» выберите папку с MD-файлами, задайте chunk_size и overlap и выберите стратегию: Fixed режет текст на равные куски, Structure режет по заголовкам Markdown с сохранением секций, «Обе» индексирует двумя способами. Нажмите «Проиндексировать»: файлы читаются, режутся на чанки, эмбеддируются локальной моделью через Ollama и сохраняются в Chroma. Прогресс отображается по файлам.

## Сравнение режимов

Вкладка «Сравнение» прогоняет 10 контрольных вопросов в двух режимах — с RAG и без RAG. Для каждого вопроса выставляется оценка: Хорошо, Частично или Плохо. Внизу агрегированная статистика показывает, какой режим отвечает лучше.

## Инструменты (MCP)

Агент умеет вызывать внешние инструменты: напоминания (создать, список, удалить), новости (поиск по RSS, сводка, сохранение в файл), город по IP и погоду. Инструменты выполняются через MCP-серверы; вызовы отображаются под ответом ассистента.
