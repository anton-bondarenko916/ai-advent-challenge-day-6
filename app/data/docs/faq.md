# Часто задаваемые вопросы

## Учётные записи и ключи

### Где взять ключ DeepSeek API?

Ключ выпускается в личном кабинете платформы DeepSeek в разделе API Keys. Скопируйте его в файл .env в переменную DEEPSEEK_API_KEY. Ключ не публикуйте в репозитории: .env добавлен в .gitignore.

### Работает ли приложение без ключа?

Да, в mock-режиме: python main.py --mock. Приложение имитирует ответы модели, не обращаясь к сети. Все интерфейсы, задачи и база знаний работают, но ответы генерируются локально.

## Данные и приватность

### Где хранятся мои данные?

Всё хранится локально: история диалога и профили в data/chat_history.db, задачи в data/tasks.db, долговременная память в data/long_memory.db, векторная база знаний в app/data/chroma_db. Запросы уходят только к DeepSeek API и локальной Ollama.

### Как полностью удалить приложение?

Удалите папку проекта — все данные лежат внутри неё, в подкаталоге data.

## Модели

### Какие модели поддерживаются?

deepseek-v4-flash — быстрая и дешёвая модель для повседневных задач; deepseek-v4-pro — более сильная модель для сложных рассуждений. Модель выбирается на вкладке «Настройки» и сохраняется в профиле.

### Можно ли поменять температуру и лимит токенов?

Да, на вкладке «Настройки»: температура от 0.0 до 2.0 и max_tokens для ответа. Значения сохраняются в настройках активного профиля.

## Эмбеддинги

### Нужен ли интернет для RAG?

Интернет не нужен: эмбеддинги считает локальная Ollama с моделью nomic-embed-text. Нужен лишь запущенный сервис ollama serve и загруженная модель.
