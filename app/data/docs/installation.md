# Установка приложения

Здесь описана установка DeepSeek Chat на все поддерживаемые платформы.

## Требования

Для работы нужен Python 3.11 или новее и ключ DeepSeek API. Ключ получается в личном кабинете платформы DeepSeek и хранится в файле .env в корне проекта.

## Windows

1. Скачайте установщик Python 3.11+ с официального сайта python.org.
2. При установке отметьте галочку «Add Python to PATH».
3. Распакуйте архив проекта в любую папку, например C:\Apps\deepseek-chat.
4. Откройте командную строку в папке проекта и выполните: pip install -r requirements.txt.
5. Скопируйте .env.example в .env и вставьте свой ключ DeepSeek API в переменную DEEPSEEK_API_KEY.
6. Запустите приложение командой python main.py.

Если антивирус блокирует запуск, добавьте папку проекта в исключения.

## Linux

1. Установите Python 3.11+ через пакетный менеджер дистрибутива (например, sudo apt install python3.11).
2. Создайте виртуальное окружение: python3 -m venv venv и активируйте его: source venv/bin/activate.
3. Установите зависимости: pip install -r requirements.txt.
4. Скопируйте .env.example в .env и укажите ключ DEEPSEEK_API_KEY.
5. Для графического режима установите python3-tk: sudo apt install python3-tk.
6. Запустите приложение командой python main.py.

## macOS

1. Установите Homebrew, затем Python: brew install python@3.11.
2. Дальнейшие шаги совпадают с Linux: venv, pip install -r requirements.txt, ключ в .env, запуск python main.py.

## Проверка установки

После запуска откроется окно чата. Введите любое сообщение — если настройка выполнена верно, придёт ответ модели. Без ключа запускайте приложение с флагом --mock: оно работает без сети и имитирует ответы.
