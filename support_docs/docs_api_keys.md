# Документация: API-ключи и лимиты

## Создание API-ключа

API-ключ создаётся в разделе «Настройки → API». Ключ показывается один
раз при создании — сохраните его сразу. Один аккаунт может держать до
5 активных ключей; отозванный ключ перестаёт работать мгновенно.

## Лимиты запросов

Базовый лимит — 60 запросов в минуту на аккаунт. При превышении API
возвращает код 429; повторяйте запрос после паузы из заголовка
`Retry-After`. Лимит считается по всем ключам аккаунта суммарно.

## Ошибки 401

Ошибка 401 означает, что ключ не принят: ключ отозван, указан с
опечаткой или передан без схемы `Bearer` в заголовке `Authorization`.
Проверьте ключ в разделе «Настройки → API» и создайте новый, если
текущий не отображается в списке активных.
