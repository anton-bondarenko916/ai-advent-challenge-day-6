# Telegram-бот для локальной Ollama (ТЗ ai_1_31)

Бот хостится на вашем ПК и отвечает пользователям из локальной модели.
Соединения — **только исходящие** (long polling): порты наружу не
открываются, брандмауэр/DDNS/Nginx не нужны, работает из любой точки
мира и за CGNAT провайдера.

```text
[Телефон] ⇄ Telegram ⇄ telegram_bot.py (ваш ПК, long polling)
                              ⇅ POST http://127.0.0.1:11434/api/chat
                           Ollama + data/telegram_bot.db (история)
```

## Шаг 1. Создание бота и белый список (5 минут)

1. В Telegram откройте **@BotFather** → `/newbot` → имя и username.
   Скопируйте токен вида `123456789:AA...`.
2. Узнайте свой числовой ID у **@userinfobot** (например, `123456789`).
3. Впишите в `.env` в корне проекта:

```env
TELEGRAM_BOT_TOKEN=123456789:AAxxxxxxxxxxxxxxxxxxxxxxxx
TELEGRAM_ALLOWED_IDS=123456789
# Необязательно (иначе берётся первая установленная модель):
# TELEGRAM_MODEL=qwen2.5:7b
```

Белый список — обязателен: все, кого нет в `TELEGRAM_ALLOWED_IDS`,
получают отказ (их ID пишутся в `telegram_bot.log` — удобно добавить
родных/коллег). Разрешено несколько: `TELEGRAM_ALLOWED_IDS=111,222,333`.

## Шаг 2. Запуск

```cmd
cd C:\AI\AI_2_1\deepseek-chat-app
python telegram_bot.py
```

Журнал — `telegram_bot.log` (UTF-8) + консоль. Остановка — Ctrl+C.

### Автозапуск после перезагрузки ПК

```cmd
schtasks /Create /TN "Ollama Telegram Bot" /SC ONSTART /RU SYSTEM ^
  /TR "cmd /c cd /d C:\AI\AI_2_1\deepseek-chat-app && python telegram_bot.py"
```

Рабочий каталог важен: иначе бот не найдёт `.env` и БД. Удалить задачу:
`schtasks /Delete /TN "Ollama Telegram Bot" /F`.

## Команды бота

| Команда | Действие |
|---|---|
| *(любое сообщение)* | ответ из локальной модели, с учётом вашей истории |
| `/model` | инлайн-кнопки: модели из `/api/tags`; выбор запоминается |
| `/clear` | очистить историю диалога (модель «забыла» разговор) |
| `/help` | справка |
| `/start` | приветствие + текущая модель |

## Как это работает

* История диалогов — SQLite `data/telegram_bot.db`, раздельная на
  каждого пользователя, переживает перезапуск бота; в контекст модели
  уходит последние 20 сообщений (`TELEGRAM_HISTORY_LIMIT`).
* Ответы идут через `POST /api/chat` без стриминга; во время генерации
  виден индикатор «печатает…». Ответы длиннее ~4000 символов приходят
  несколькими сообщениями.
* Если Ollama не запущена, бот ответит предупреждением и продолжит
  работать (`ollama serve` на ПК).

## Чего НЕ делать

* ❌ Не выкладывать токен бота (он даёт полный контроль над ботом);
  засветили — отозвите у @BotFather (`/revoke`).
* ❌ Не добавлять в белый список незнакомцев — они получат доступ к
  вашей машине через модель (включая MCP-инструменты в будущих версиях).
* ❌ Не включать webhook — для него нужен публичный HTTPS, теряется
  смысл схемы.

## Состав в коде

| Файл | Назначение |
|---|---|
| `telegram_bot.py` | точка входа: aiogram 3, хендлеры, гейт доступа, typing, разбивка |
| `src/tg_bot_logic.py` | белый список, `split_message`, `ChatTurn` (история → Ollama → история) |
| `src/tg_ollama_client.py` | async-клиент `/api/chat` и `/api/tags` (таймаут под холодную загрузку) |
| `src/tg_storage.py` | SQLite: история диалогов и выбранная модель на пользователя |
| `src/config.py` | `TELEGRAM_*` ключи, `get_telegram_settings()` |
| `tests/test_telegram_bot.py` | офлайн-тесты (Telegram API замокан, БД временная) |
